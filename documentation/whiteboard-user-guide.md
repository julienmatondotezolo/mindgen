# Whiteboard User Guide

## Introduction

The Whiteboard is a powerful mind-mapping and diagramming tool that allows you to create, edit, and collaborate on visual diagrams in real-time. This guide covers the basic and advanced features of the whiteboard.

## Getting Started

### Basic Navigation

- **Pan**: Hold the spacebar and drag to move around the canvas
- **Zoom In/Out**: 
  - Use the mouse wheel to zoom in and out
  - Use the zoom controls in the bottom-right corner
  - Ctrl + Mouse wheel for precise zooming
- **Fit to Screen**: Click the "Fit to Screen" button to view all content

### Creating Shapes

1. Select a shape tool from the toolbar (Rectangle, Ellipse, or Diamond)
2. Click on the canvas to place the shape
3. The shape will be created with default properties and automatically selected

### Selection and Manipulation

- **Select a Shape**: Click on any shape to select it
- **Multi-select**: 
  - Hold Shift and click on multiple shapes
  - Or drag from an empty area to create a selection rectangle
- **Move**: Click and drag a selected shape to move it
- **Resize**: Drag any of the handles around a selected shape to resize it

### Creating Connections

1. Hover over a handle on any shape (small circles appear on the edges)
2. Click and drag from the handle to another shape
3. Release on a handle of the target shape to create a connection
4. The connection will be created with default properties

## Working with Shapes

### Editing Shapes

When a shape is selected, you can modify its properties using the selection tools:

- **Change Color**: Select a color from the color picker
- **Add/Edit Text**: Click on a shape to add or edit text
- **Delete**: Select a shape and press Backspace or Delete

### Formatting Options

Selected shapes can be customized with various formatting options:

- **Border Style**: Change between solid and dashed borders
- **Text Formatting**: Adjust font weight and text transformation
- **Layer Order**: Bring shapes forward or backward in the stacking order

## Working with Connections

### Editing Connections

When a connection is selected, you can modify its properties:

- **Line Style**: Change between solid and dashed lines
- **Arrow Style**: Add or remove arrowheads at either end
- **Line Thickness**: Adjust the thickness of the connection
- **Line Shape**: Change between straight, curved, or step lines

### Connection Labels

1. Select a connection
2. Click on the label area
3. Type your text and press Enter to save

## Collaborative Features

### Real-time Collaboration

The whiteboard supports real-time collaboration with these features:

- **Cursor Presence**: See other users' cursors in real-time
- **Selection Indication**: See which shapes other users have selected
- **Real-time Updates**: All changes are immediately visible to all collaborators

### Permissions

Different permission levels control what actions users can perform:

- **Read**: View the whiteboard only
- **Update**: Create and modify shapes and connections
- **Delete**: Remove shapes and connections

## Saving and Exporting

### Auto-save

The whiteboard automatically saves your work:
- When switching tabs
- Before closing the browser
- Before navigating away
- Periodically during editing

### Export Options

To export your whiteboard:
1. Look for the export button in the toolbar
2. Choose to export as an image (PNG format)
3. The image will be downloaded to your device

## Keyboard Shortcuts

| Action | Shortcut |
|--------|----------|
| Pan canvas | Space + drag |
| Delete selected | Backspace or Delete |
| Complete current action | Enter |
| Undo | Ctrl/Cmd + Z |
| Redo | Ctrl/Cmd + Shift + Z or Ctrl/Cmd + Y |
| Zoom in | Ctrl/Cmd + + |
| Zoom out | Ctrl/Cmd + - |
| Fit to screen | Ctrl/Cmd + 0 |

## Tips and Best Practices

### For Better Performance

- Limit the number of shapes and connections for smoother performance
- Use the "Fit to Screen" button to easily navigate large diagrams
- Save your work regularly, especially for complex diagrams

### For Better Organization

- Use different shapes to represent different types of information
- Use consistent color coding for related concepts
- Keep connections clean and avoid crossing lines when possible
- Add clear labels to connections to explain relationships

### For Collaboration

- Communicate with collaborators about who is working on which sections
- Use the cursor presence feature to see where others are working
- Establish color-coding conventions with your team

## Troubleshooting

### Common Issues

- **Performance Slowdowns**: If the whiteboard becomes slow, try reducing the number of elements or refreshing the page
- **Connection Issues**: If real-time updates stop working, check your internet connection
- **Saving Problems**: If changes aren't saving, ensure you have the correct permissions

### Getting Help

If you encounter issues not covered in this guide:
- Check the FAQ section
- Contact support with specific details about your issue
